# Project Reboot
## RACI Matrix

The RACI matrix defines ownership and communication responsibilities for key project activities.

### Roles

- **PM** — Project Manager
- **PO** — Product Manager
- **ENG** — Engineering Team
- **UX** — UX/UI Team
- **COMP** — Compliance Team
- **FIN** — Finance Team
- **MKT** — Marketing Team
- **SM** — Senior Management

### RACI Legend

| Code | Meaning |
|---|---|
| R | Responsible — Performs the work |
| A | Accountable — Owns the outcome |
| C | Consulted — Provides input |
| I | Informed — Kept updated |

## Key Observations

- The Project Manager coordinates the overall recovery process and maintains project visibility.
- The Product Manager owns product priorities and requirements.
- The Engineering Team owns technical development activities.
- The Compliance Team is accountable for compliance review.
- Senior Management provides final accountability for the launch decision.
- Cross-functional consultation is required for activities that affect multiple teams.
